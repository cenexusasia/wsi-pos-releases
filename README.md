# WSI POS — release artifacts

This repository hosts **release artifacts only** for WSI POS, the local-first
point-of-sale for Philippine cafés and restaurants. Product source is not
hosted here.

- Product site: https://pos.wsi.asia
- Contact: support@wsi.asia

Download the latest build from the [Releases](../../releases) page, and read the
release notes before installing — builds are currently **not code-signed**, so
verify the published SHA-256 after downloading.
